📖 Documentation

Lists

  • Create a new list, rename it, or switch the active list from Settings → Lists.
  • Archive a finished list to History to keep it out of the way, or delete it permanently.
  • Each list has its own items and progress.

Items

  • Tap ＋ to add an item with name, category, quantity and unit.
  • Tap an item to mark it purchased; tap again to unmark.
  • Long-press an item (or right-click on desktop) to edit it.
  • Use the Search bar to filter items.

Gestures

  • Swipe left — favourite / un-favourite an item.
  • Swipe right — delete an item (with confirmation).
  • Tap — toggle purchased.
  • Long-press — edit the item.

Print (POS receipt)

  • Long-press the ＋ button to print the current list as an 80 mm thermal receipt.
  • In the print dialog, select your 80 mm / thermal printer (or Custom 80×297 mm) for correct sizing.
  • Receipts always print in black on white, regardless of theme, with a trailing feed for the auto-cutter.
  • Purchased items are hidden from the printed receipt.

QR Share & Import

  • Open Settings → Lists, tap the ⋮ menu on a list, then Share QR.
  • Scan the QR (or paste the payload) from Settings → Data → Share / Import with QR to load that list.
  • Very large lists use Copy Payload instead — paste it into another copy of the app.
  • Use the 📨 button in the header to share the active list — tap to send as SMS, long-press to copy the payload.

Backup & Data

  • Export saves all data as a .json backup file.
  • Import restores a backup file.
  • Clear purchased items, or clear all data, from the Data section.

Appearance & Offline

  • Switch Light / Dark theme from Settings.
  • This app works offline once loaded and can be installed to your home screen.
