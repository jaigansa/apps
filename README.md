## 🛠️ Tech Stack & Features
- Built with **Vanilla HTML, CSS, and JavaScript**.
- Includes **Tailwind CSS** integration in select apps for rapid styling.
- Responsive, mobile-first design architecture.
- Progressive Web App (PWA) capabilities enabled in several apps for offline usage.

## 💻 Local Setup
To run these applications locally, simply clone the repository and serve the files:

```bash
git clone https://github.com/jaigansa/apps.git
cd apps
# Use any local web server, for example with Python:
python -m http.server 8000
```
Then open `http://localhost:8000/index.html` in your browser.
